# AeroBot
**AeroBot** is a fun and handy Slack Bot I built using Java Script.
It can do a bit of everything, it pulls live orbital data for the International Space Station, it can tell the resistance of a resistor by its color bands and calculate your weight on other planets. It runs **24/7** as it is hosted on **Hack Club Nest**!
## What can it do
* `/aerobot-ping` - Checks if the alive and responding
* `/aerobot-help` - Pulls up all the commands of AeroBot
* `/aerobot-iss` - Pulls live data of the ISS showing its exact coordinate, speed and visibility
* `/aerobot-resistor [band1] [band2] [band3]` - Type in the color bands of the resistor and you will get the resistance of it
* `/aerobot-weight [your weight]` - Type in your weight on Earth and it will calculate your weight on other planets
